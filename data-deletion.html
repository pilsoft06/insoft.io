1. 계정 및 자체 서버

Insoft의 모바일 앱 및 게임은 회원가입이나 로그인 기능을 제공하지 않으며, 자체 서버에 이용자의 계정이나 게임 진행 데이터를 저장하지 않습니다. 따라서 별도로 삭제할 Insoft 계정은 없습니다.

2. 기기에 저장된 데이터 삭제

기기에 저장된 게임 진행 상황, 설정 및 캐시 등을 삭제하려면 사용하는 운영체제에 맞는 방법을 선택해 주세요.

iPhone 및 iPad

설정 → 일반 → iPhone 저장 공간(또는 iPad 저장 공간) → 해당 게임 → 앱 삭제

“앱 정리하기”는 문서와 데이터를 보관하므로 데이터 삭제를 원할 때는 “앱 삭제”를 선택해 주세요.

Android

Android에서는 아래 방법으로 앱 데이터를 삭제할 수 있습니다.
설정 → 앱 → 해당 게임 선택 → 저장공간 또는 저장공간 및 캐시 → 데이터 삭제 또는 저장공간 비우기

메뉴 이름은 기기와 운영체제 버전에 따라 다를 수 있습니다. 데이터를 삭제하면 게임 진행 상황과 설정이 초기화되며, 별도의 백업이 없는 경우 복구되지 않을 수 있습니다. 기기 또는 클라우드 백업에 저장된 사본이 있다면 해당 백업 서비스의 설정에서 별도로 관리해야 합니다.

3. 외부 광고·측정 서비스의 데이터

서비스에는 광고 제공 및 광고 성과 측정을 위한 외부 SDK가 포함될 수 있습니다. 해당 SDK를 통해 처리되는 데이터와 처리 목적은 개인정보처리방침 및 각 제공자의 정책에서 확인할 수 있습니다.

기기에서 앱 데이터를 삭제하거나 앱을 제거하는 것만으로 외부 서비스가 이미 수집한 데이터까지 자동으로 삭제되는 것은 아닙니다.

관련 데이터의 삭제 방법을 문의하려면 아래 이메일로 연락해 주세요. 운영자가 처리할 수 있는 요청은 관련 법령에 따라 처리하고, 외부 제공자가 별도로 관리하는 데이터는 해당 제공자의 정책과 이용 가능한 삭제 절차를 안내하겠습니다.
